# Ενημερώσεις εφαρμογής & υπογραφή (Windows)

## 1. Αυτόματες ενημερώσεις

Η εφαρμογή ελέγχει για νέα έκδοση από έναν **φάκελο στο διαδίκτυο** (https:// ή http://) που περιέχει,
για κάθε έκδοση, τρία αρχεία από τον φάκελο `release/` του build:

- `latest.yml`
- `S. Doukas S.A Setup X.Y.Z.exe`
- `S. Doukas S.A Setup X.Y.Z.exe.blockmap`

Μπορεί να είναι οποιοδήποτε hosting που σερβίρει στατικά αρχεία (δικό σας site, GitHub Release σε δημόσιο repo, S3 κ.λπ.).
Δεν υπάρχει κάτι που να λειτουργεί χωρίς να ανεβάσετε εσείς τα αρχεία.

### Ρύθμιση (μία φορά)
- **Ανά υπολογιστή:** Settings → *Ενημερώσεις εφαρμογής* → βάλτε τη διεύθυνση του φακέλου → Αποθήκευση.
- **Για όλες τις εγκαταστάσεις:** γράψτε τη διεύθυνση στο `electron/update-config.json` (`"feedUrl"`) πριν το build.
  Η ρύθμιση ανά υπολογιστή υπερισχύει.

Αν δεν έχει οριστεί διεύθυνση, η εφαρμογή δεν κάνει καμία σύνδεση.

### Κυκλοφορία νέας έκδοσης
1. Αλλάξτε το `"version"` στο `package.json` (π.χ. `1.0.1`). Πρέπει να είναι **μεγαλύτερο** από την εγκατεστημένη.
2. `npm run dist:win`
3. Ανεβάστε τα 3 αρχεία του βήματος από το `release/` στον φάκελο ενημερώσεων.
4. Οι εγκατεστημένες εφαρμογές το βρίσκουν στην εκκίνηση (μετά από λίγα δευτερόλεπτα) ή από το κουμπί *Έλεγχος για ενημερώσεις*.
   Κατεβάζει στο παρασκήνιο και ρωτά «Επανεκκίνηση και ενημέρωση;». Το πρόχειρο της παραγγελίας διατηρείται.

> Η πρώτη εγκατάσταση που κάνει αυτόματη ενημέρωση πρέπει να είναι έκδοση που περιέχει ήδη αυτόν τον μηχανισμό (1.0.0 και μετά).

## 2. Υπογραφή κώδικα (code signing)

Χωρίς πιστοποιητικό, τα Windows (SmartScreen) δείχνουν προειδοποίηση «Άγνωστος εκδότης» στην εγκατάσταση.
Το πρόγραμμα δεν μπορεί να το αποφύγει μόνο του· χρειάζεται πιστοποιητικό υπογραφής κώδικα (OV ή EV) από αναγνωρισμένη αρχή.

Όταν αποκτήσετε πιστοποιητικό (`.pfx`), το build είναι έτοιμο να το χρησιμοποιήσει με μεταβλητές περιβάλλοντος:

```
set CSC_LINK=C:\path\certificate.pfx
set CSC_KEY_PASSWORD=ο_κωδικός
npm run dist:win
```

Χωρίς πιστοποιητικό (όπως σήμερα) χτίστε με:

```
set CSC_IDENTITY_AUTO_DISCOVERY=false
npm run dist:win
```

Σημείωση: μην ορίσετε `publisherName` στο `package.json` αν το installer δεν είναι υπογεγραμμένο, γιατί οι ενημερώσεις θα αποτυγχάνουν στον έλεγχο υπογραφής.
